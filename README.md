# Аэропорт-магнат 3D

Браузерный 3D-симулятор аэропорта на чистом WebGL, без библиотек и сборки. Стройте полосы, рулёжки, гейты и терминалы, заключайте контракты с авиакомпаниями, развивайте ранг директора и открывайте новые аэропорты.

## Как запустить

Откройте `index.html` в браузере: всё работает и с локального диска, и с любого статического хостинга (например, GitHub Pages). Для локального сервера можно выполнить `npm start`.

Игра сохраняется автоматически каждые 8 секунд в `localStorage` с запасной копией в IndexedDB. Через меню ☰ копию можно скачать файлом и загрузить обратно. Сохранения предыдущих версий загружаются и переносятся автоматически.

## Игровой цикл

1. Самолёт запрашивает посадку, садится на ВПП и по рулёжкам едет к свободной стоянке.
2. На гейте самолёт обслуживается и затем выруливает на взлёт. Гейту нужен терминал в радиусе 10 клеток.
3. За вылет вы получаете выручку; содержание построек списывается в полночь.
4. Контракты с авиакомпаниями приносят регулярные рейсы и больше денег. Опоздания снижают оплату и репутацию.
5. Цели аэропорта открывают следующую локацию: Зелёная долина → Островной хаб → Мегаполис → Пустыня → Горный курорт.

## Возможности

- **5 аэропортов** со своим рельефом, погодой, спросом и особым зданием.
- **14 типов построек**: ВПП (можно повернуть), рулёжки, терминалы, гейты, службы, топливо, диспетчерская, парковки, магазины, грузовой терминал и особые здания локаций.
- **7 авиакомпаний**, включая грузовую Polar Cargo, с окнами расписания.
- **Погода** — ясно, облачно, дождь, туман, шторм, снегопад, песчаная буря, жара. Она влияет на посадку и обслуживание и отрисовывается частицами.
- **Решения директора**: чартеры, премии службам, проверки, реклама, цены на топливо, фестивали.
- **Экономика**: аэропортовые сборы, кредиты, график прибыли по дням и статьи доходов и расходов.
- **Прогрессия**: ранг директора (до 30), очки развития, 9 веток перков, 21 достижение и постройки, открывающиеся по рангу.
- **Живой трафик**: самолёты кружат в зоне ожидания, снижаются на посадку, набирают высоту после взлёта и уходят на запасной аэродром, если ждали слишком долго. Ночью горят огни ВПП и окна терминалов.

## Управление

| Действие | Мышь и клавиатура | Сенсорный экран |
|---|---|---|
| Вращать камеру | тянуть карту, Q / E | тянуть одним пальцем |
| Сдвинуть камеру | правая кнопка, пробел + тянуть, стрелки | двумя пальцами или режим ✥ |
| Масштаб | колесо, + / − | щипок, кнопки + / − |
| Постройки | 1–5, R — повернуть, Enter — подтвердить, Esc — отменить | панель «Строить», кнопки ⟳ и «Построить» |
| Снос | 6 или ⌫, затем подтверждение | ⌫, касание постройки, «Снести» |
| Пауза | P | панель скорости на карте |

Рулёжку можно рисовать несколькими штрихами до подтверждения. При сносе можно провести по рулёжкам, чтобы выбрать сразу несколько участков.

## Структура проекта

```
index.html          разметка и подключение скриптов
css/style.css       стили: десктоп, планшет, телефон, ландшафт
js/data.js          контент: постройки, самолёты, локации, авиакомпании, перки, достижения
js/state.js         состояние аэропорта, сетка, проверка и миграция сохранений
js/sim.js           симуляция: сеть рулёжек, маршруты, трафик, экономика, погода, прогрессия
js/storage.js       localStorage + IndexedDB, экспорт и импорт
js/render.js        WebGL-рендер: модели из треугольников, огни, погода
js/ui.js            панели, вкладки, модальные окна, уведомления
js/input.js         мышь, касания, клавиатура, черновики стройки и сноса
js/main.js          запуск и игровой цикл
tests/              тесты симуляции (Node) и браузерный сценарий (Playwright)
```

Скрипты подключаются как обычные `<script>` и делят одну глобальную область видимости, поэтому игра открывается даже по `file://`. Порядок подключения важен и проверяется тестом.

## Тесты

```bash
npm test          # симуляция в Node: трафик, контракты, грузы, кредиты, миграция сохранений
npm run test:e2e  # браузерный сценарий: стройка, снос, контракты, финансы, телефон, перенос сохранения
```

Для браузерного теста нужен Playwright с Chromium (`npm i -D playwright && npx playwright install chromium`).
